# 상담 패키지 이용기간 고지 — 웹 조사 요지 (2026-09-11)

> **리더 확정(2026-09-16)**: 아래 「확정 공개 문구」·제품 SSOT가 이전 조사 결론(회기 소진제·달력일수 제한 없음)을 **대체**한다. 조사 본문(법령·PG 관행)은 배경 참고용으로 유지한다.

## 결론 (제품 반영)

- **핵심 의무/심사 포인트는 “이용기간·유효기간을 결제 전 명시”**이다. 특정 PG가 상담 패키지에 **「90일」을 강제한다는 공개 근거는 확인되지 않았다.** 허위 「90일」 하드코딩 금지.
- **제품 SSOT (리더 확정)**:
  - **단회기**: 결제일부터 **2개월** 내 소진
  - **패키지(최대 20회기)**: 결제일부터 **1년** 내 소진
  - **결제**: **일시불만** (정기결제·구독 없음)
  - **무제한 유효기간 없음**
- 공개 UI·약관·샵 구매면은 위 SSOT로 동기화한다. (이전 「잔여 회기 소진 시까지 / 달력일수 자동 만료 없음」 결론은 폐기)

상담 패키지(회기형 용역)는 상품권·선불전자지급수단과 별개이다. 선불전자지급수단의 「유효기간 1년 이상」「만료 30일 전 3회 안내」「잔액 90% 환급」 등은 **전자금융 선불업** 맥락이며, 「90일」을 패키지 이용기간으로 강제하는 근거가 아니다.
