# 타기관 연계 → (이후) 바우처 연계

제품 정의 SSOT. ADR·구현 없음.

| 항목 | 정의 |
|------|------|
| 순서 | 타기관 연계 → (이후) 바우처 연계 |
| 타기관 | 본류는 **내담자 등록 유형**(별 타기관 화면은 본류 아님). 유형=타기관일 때만 기관 정보·초기선납. **배정**은 그 유형을 읽음. **가예약 전용 / 기관연계 전용**(교차 배정 금지). 기관연계=고정 금액(가예약 아님). 스케줄 색 구분. 월 단위 고정 아님(월결제는 후속). 월말 상담내역 / 일지 분리(오류가 회기 일지에 전파 금지) |
| 바우처 | 지금 안 함 |
| 회기권 | 미변경 |
| 저장 | 타기관은 회기 매핑 플래그가 아니라 **Flyway로 별 저장소** 분리. 기존 회기 행 유지, 타기관 건만 마이그(운영 수동 SQL 아님). 상담일지도 타기관 쪽으로 분리(회기 일지 테이블에 오류 전파 금지). 바우처 마이그 없음(후속, 실데이터 없음). |
| 최소 구현 | 매핑 타입 1 + 회기 게이트 우회 금지(타기관은 별 게이트) + 별 일지 서비스 |
| 하지 않음 | 별 타기관 화면을 본류로, 가예약↔기관연계 교차 배정, 기관연계=가예약, 바우처 UI, 월결제·결제 주기 UI, rem 예외, 공용 일지에 구멍, 월 인보이스 풀세트, 이 브랜치에서 Flyway/코드 구현 |
