## 3. 섹션 · 컴포넌트 · 카피

### 0. 히어로
- h1: 「{centerName} 심리상담 서비스 안내」 (예: 마인드가든 심리상담센터 심리상담 서비스 안내)
- **정의 한 줄:** 테넌트 콘텐츠 `서비스 한 줄 소개` (필드 있는지 구현 시 확인). 없으면 폴백 「{centerName}는 상담사와 1:1로 만나 마음의 어려움을 함께 살펴보는 심리상담센터예요.」 (플랫폼 공통 문구 · 센터 사실을 덧붙이지 않음)

- 사진 (선택): 테넌트 콘텐츠 이미지 · 마인드가든은 `shared/mindgarden/photos` 센터 실사 · 사람이 보이면 블러 · 280×200 r16 `object-fit:cover` · `alt`=「{centerName} 상담실」 · 없으면 1열

| 열 | 폭 | 내용 |
|---|---|---|
| 상품 | `minmax(200px,1fr)` | 이름 15/700 ink + 상세 13 mute (줄바꿈 허용, 말줄임 금지) |
| 구성 | 120 | 「{n}회기 · 1회 {N}분」 (없는 값 생략) |
| 이용기간 | 140 | 「결제일부터 {validityMonths}개월」 · null이면 「—」 |
| 가격 | 140 · 오른쪽 · tabular-nums | 「{price}원」 15/700 · 할부 조건 충족 시 아래 12.5 mute 「카드 할부 가능」 |

## 6. 확인 필요

1. **할부 vs 몰 「카드 결제 · 일시불」:** 몰 스펙은 일시불 고정. 이 페이지는 5만 원 이상 할부 안내 → 실제 결제창 할부 허용 여부와 몰 문구를 맞춰야 함.
2. **예시 이용기간 차이:** 리더 예시 단회기 2개월 / 20회기 6개월 vs 몰 시안 단회기 3개월. 실제 값은 `validityMonths`라 화면 문제는 아니지만 예시 통일 여부.
3. 환불 전용 공개 경로 없음 → `/legal/terms#refund` 앵커로 충분한지 (PG 크롤 기준).
4. 상담 종류·상담사 자격·정의 한 줄·센터 소개 문단의 **테넌트 설정 필드 유무** (없으면 테넌트 콘텐츠 설정 추가 = 백엔드 변경).
5. 상담사 자격 공개 동의·토글 기본값.
6. 대표·사업자등록번호·통신판매신고번호가 .dev/운영 레코드에 들어 있는지 (PG 심사 필수).
7. 「1회 {N}분」 출처 (상담 종류 vs 상품 필드).
8. 환불 요약 필드 유무 (없으면 조항 앞 2문장 규칙) · 문구 속 「1회 90,000원」이 단회기 가격 변경 시 함께 갱신되는지.
9. 공개 면 렌더 방식 (SSR/프리렌더로 첫 HTML에 본문 포함 가능한지).
