## 2. P0 필수 시안 상세 (V1 ~ V5)

### V1. 전역 기간 Pill
- **위치**: 시각화 그룹 우측 상단
- **구성**: 일간 | 주간 | 월간 | 년간
- **스타일**: `mg-v2-ad-b0kla__pill`, 활성 상태 배경 `var(--mg-color-primary-main)`, 비활성 배경 `var(--mg-color-surface-main)`

### V2. 스택/그룹 바 (상담 현황)
- **데이터**: 기간별 예약, 진행, 완료 건수
- **형태**: Stacked Bar (누적 막대) 권장. 전체 볼륨과 비율을 동시에 확인.
- **높이**: 200px (차트 영역)

### V3. 멀티라인 3선 (추이 비교)
- **데이터**: 예약, 진행, 완료 3가지 시리즈
- **형태**: Line Chart (Smooth curve). Hover 시 툴팁으로 3개 수치 동시 표시.
- **높이**: 200px

### V4. 기간 합계 KPI 미니카드 3종 + 스파크라인
- **구성**: 예약, 진행, 완료 각각의 총합을 표시하는 미니 카드 3개 나열 (가로 배치)
- **내부**: 숫자(24px, 600) + 우측에 작은 스파크라인(최근 추이)
- **높이**: 200px 내에 3개 카드를 그리드로 배치 (또는 세로 리스트형)

### V5. 상태 도넛 / 프로그레스 링
- **데이터**: 선택된 기간 내 전체 건수 대비 예약/진행/완료 비율
- **형태**: Donut Chart. 중앙에 총 건수 표시. 우측에 커스텀 범례(비율 % 포함).
- **높이**: 200px

## 3. 시리즈 색상 토큰 (중요)

상담 상태별로 명확한 시각적 구분을 위해 B0KlA 팔레트를 매핑합니다. (Hex 하드코딩 금지)

| 시리즈 | 색상 토큰 | 설명 |
|--------|-----------|------|
| **예약** (Booked) | `var(--mg-color-secondary-main)` | 대기 중인 상태를 나타내는 차분한 보조색 |
| **진행** (In Progress) | `var(--mg-color-accent-main)` | 현재 활성화된 상태를 강조하는 포인트 색상 |
| **완료** (Completed) | `var(--mg-color-primary-main)` | 성공적으로 끝난 상태를 나타내는 주조색 |

## 4. 컴포넌트/블록별 토큰·간격·높이

| 요소 | 토큰 / 클래스 / 수치 |
|------|----------------------|
| **그룹 래퍼 배경** | `var(--mg-color-surface-main)` |
| **그룹 래퍼 테두리** | `1px solid var(--mg-color-border-main)`, `border-radius: 16px` |
| **그룹 패딩** | 데스크톱 `24px` (`var(--mg-spacing-lg)`), 모바일 `16px` |
| **그룹 내부 Gap** | 행/열 간격 `16px` (`var(--mg-spacing-md)`) |
| **섹션 제목 악센트** | 폭 `4px`, `var(--mg-color-primary-main)`, `border-radius: 2px` |
| **섹션 제목 텍스트** | `16px`, `font-weight: 600`, `var(--mg-color-text-main)` |
| **차트 카드 배경** | `var(--mg-color-background-main)` (그룹 배경과 대비) |
| **차트 카드 높이** | 기본 `200px` (차트 영역) + 패딩 `16px` |

## 5. 상태별 UX (Empty / Loading / Zero)

| 상태 | UX 처리 방안 |
|------|--------------|
| **Loading** | 차트 영역에 Skeleton UI (`mg-v2-skeleton`) 표시. 전체 레이아웃 틀은 유지. |
| **Empty** (데이터 없음) | 차트 대신 중앙에 빈 상태 아이콘 + "해당 기간의 데이터가 없습니다" 텍스트 렌더링. (`var(--mg-color-text-secondary)`) |
| **진행 건수 ≈ 0** | IN_PROGRESS가 매우 적어 렌더링이 안 보일 경우: 툴팁에서 명시적으로 `0건` 노출. 스택 바에서는 최소 높이(1~2px)를 주지 않고 실제 비율대로 렌더링하되, 범례와 KPI 카드(V4)에서 `0건`임을 명확히 인지시킴. |

## 7. 코더 핸드오프 섹션 (구현 가이드)

### 7.1 구현 우선순위 (Phase 2)
1. **API 연동**: `monthlyData`, `weeklyData`, `dailyData`, `yearlyData`에 `inProgressCount` 필드 매핑.
2. **UI 래퍼 구성**: `AdminDashboardVisualizationGroup` 레이아웃(2+1 그리드) 및 기간 Pill(4종) 동작 구현.
3. **차트 컴포넌트 교체/추가**:
   - V2 (스택 바), V3 (멀티라인), V5 (도넛) 구현.
   - Recharts 등 기존 차트 라이브러리 활용, 색상은 반드시 CSS 변수(`var(--mg-color-*)`)로 주입.
4. **KPI 카드 (V4)**: 기간 합계 계산 로직 및 스파크라인 구현.

### 7.2 데이터 필드 매핑
- **예약**: `bookedCount` (기존 유지)
- **진행**: `inProgressCount` (신규 추가 필요)
- **완료**: `completedCount` (기존 유지)

### 7.3 주의사항
- **하드코딩 금지**: 차트 색상 배열에 `#3D5246` 등 hex 값을 직접 넣지 말고, CSS 변수를 읽어오거나 테마 프로바이더를 통해 주입할 것.
- **반응형**: 모바일 화면에서 차트가 깨지지 않도록 `ResponsiveContainer` 사용 필수.
- **안전한 표시**: `toSafeNumber`, `safeDisplay` 유틸을 사용하여 `NaN`이나 `undefined` 방지.
