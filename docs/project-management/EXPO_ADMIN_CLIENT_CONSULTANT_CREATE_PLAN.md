# Expo 어드민 내담자/상담사 추가 기능 고도화 기획 (Web Parity)

## 1. 개요 및 배경
- **배경**: 현재 Expo 앱 어드민(`expo-app/`)에는 내담자(`create-client.tsx`) 및 상담사(`create-consultant.tsx`) 추가 기능이 **이미 최소 필드(MVP) 수준으로 구현되어 존재**합니다. 그러나 웹 어드민(`frontend/`)의 풀 폼(Full Form) 등록 및 상세 정보 입력 수준에는 미치지 못하고 있습니다. 
- **목표**: 사용자의 "추가 기능 도입" 요청에 따라, 기존에 존재하는 최소 기능(이름, 이메일, 연락처 등)을 웹 어드민과 동일한 수준(Web Parity)으로 확장하고, 사용성을 개선하기 위한 UI/UX 고도화 기획을 진행합니다.

## 2. 범위 및 경계
- **포함 범위**:
  - Expo 앱 내담자 추가 화면(`create-client.tsx`) 필드 확장 (주민번호, 주소, 상담 이력 등 웹 패리티 맞춤)
  - Expo 앱 상담사 추가 화면(`create-consultant.tsx`) 필드 확장 (전문분야, 자격/경력, 프로필 이미지 등)
  - 모바일 환경에 맞는 반응형/카드형 폼 레이아웃 설계
  - 기존 백엔드 API(`POST /api/v1/admin/clients`, `POST /api/v1/admin/consultants`)와의 연동 유지 및 확장 필드 매핑
- **제외 범위**:
  - 백엔드 API 신규 개발 (기존 API 재사용)
  - 초대(Invite) 전용 플로우 신규 개발 (현재 웹/백엔드에도 미존재하므로 제외, 관리자 직접 등록 후 임시 비밀번호 발급 유지)

## 3. 사용자 시나리오 (ADMIN/STAFF)
1. **진입**: 앱 어드민 > 사용자 관리 탭 > 우측 하단 FAB(+) 버튼 클릭 > '내담자 추가' 또는 '상담사 추가' 선택.
2. **입력 (내담자)**: 이름, 연락처(이메일/휴대폰) 필수 입력 후, 필요 시 주소, 주민번호 앞자리 등 부가 정보 입력.
3. **입력 (상담사)**: 이메일 필수 입력 및 중복 확인 후, 전문분야, 약력 등 부가 정보 입력.
4. **저장**: 저장 버튼 클릭 시 API 호출 및 성공 모달 노출 후 목록으로 복귀.

## 4. 의존성 및 선행 조건
- **API/DB**: 백엔드 API 및 DB는 이미 웹 어드민에서 사용 중인 풀 폼 스펙을 지원하므로 추가 작업 불필요.
- **공통 컴포넌트**: `UnifiedModal`, `AppTopBar`, `TextInput` 등 기존 컴포넌트 활용. 폼이 길어지므로 `ScrollView` 기반의 섹션 분리(카드형) 레이아웃 필요.

## 5. 단계별 실행 계획 (Phase)

| Phase | 담당 에이전트 | 목표 및 내용 |
|-------|---------------|--------------|
| **Phase 1** | `explore` | (완료) 기존 Expo 앱 내 기능 존재 여부, 웹 어드민 스펙, API 구조 파악 |
| **Phase 2** | `core-planner` | (완료) 기획서 작성 및 화면설계서 작성, 오케스트레이션 |
| **Phase 3** | `core-designer` | 화면설계서를 바탕으로 모바일 반응형 폼 레이아웃, 섹션 분리, 디자인 토큰 적용 시안/스펙 작성 |
| **Phase 4** | `core-coder` | (대기) 디자인 스펙 승인 후, 기존 `create-client.tsx`, `create-consultant.tsx` 코드 확장 구현 |

## 6. 리스크 및 제약
- **모바일 사용성**: 웹의 풀 폼을 모바일로 그대로 옮기면 스크롤이 지나치게 길어질 수 있음. 필수/선택 정보를 아코디언(Accordion)이나 스텝(Step) 형태로 분리하는 UX 고려 필요.
- **권한 처리**: 기존 `adminRole.ts`의 `CLIENT_MANAGE`, `CONSULTANT_MANAGE` 권한 로직을 그대로 유지해야 함.
