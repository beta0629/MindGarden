## 2. 세부 UI/UX 스펙

모든 카드는 기존 섹션 블록 스타일(흰색/연회색 배경, 16px radius, 회색 테두리)을 유지합니다.

### 2.1 [A 카드] 신규 내담자 유입 차트
- **제목**: "신규 내담자 유입" (기존 카드 제목 폰트 적용)
- **증감 배지 (V6 재사용)**: 제목 우측 또는 하단에 전기간 대비 증감을 주식형 배지로 표시
  - 상승: `var(--mg-badge-growth-increase-bg)` + `var(--mg-badge-growth-increase-text)` (예: `▲ 12%`)
  - 하락: `var(--mg-badge-growth-decrease-bg)` + `var(--mg-badge-growth-decrease-text)` (예: `▼ 5%`)
- **차트 타입**: 세로 막대 차트 (Bar Chart)
- **시리즈 색상**: `var(--mg-color-primary-main)` (진한 올리브 그린)
- **수치 라벨 규칙**: 
  - 각 막대 상단 중앙(Top Outside)에 수치 표시
  - 폰트 토큰: `var(--mg-v2-color-text-secondary)`, 크기 12px
  - 수치가 `0`일 경우 라벨 미노출 처리하여 차트의 복잡도를 낮춤

### 2.2 [B 카드] 요일별 상담 건수 차트
- **제목**: "요일별 상담 건수"
- **최다 요일 하이라이트 배지**: 제목 옆에 가장 높은 수치를 기록한 요일을 텍스트와 함께 표시
  - 예: `수요일` 텍스트 우측에 `[최다 · 32건]` 배지 표시
  - 배지 토큰: `var(--mg-color-surface-main)` 배경 + `var(--mg-color-text-primary)` 텍스트 (또는 기존 포인트 배지 토큰)
- **차트 타입**: 세로 막대 차트 (Bar Chart), X축은 월~일 고정
- **시리즈 색상**:
  - 기본 요일 막대: `var(--mg-color-secondary-main)` (차분한 그린/그레이 톤)
  - **최다 수치 요일 막대 (강조)**: `var(--mg-color-primary-main)` (진한 올리브 그린)
- **수치 라벨 규칙**: 
  - 막대 상단 중앙 위치, `var(--mg-v2-color-text-secondary)` 12px
  - 값이 0일 경우 미노출
  - **최다 요일의 라벨**: `var(--mg-v2-color-text-primary)` 폰트에 `fontWeight: 600`을 적용하여 굵게 강조

### 4.2 필수 사용 CSS 변수 정리
- **배경 및 레이아웃**: `var(--mg-color-background-main)`, `var(--mg-color-surface-main)`
- **테두리 및 그리드**: `var(--mg-v2-color-border-default)`
- **텍스트**: `var(--mg-v2-color-text-primary)`, `var(--mg-v2-color-text-secondary)`
- **차트 시리즈 메인 (강조)**: `var(--mg-color-primary-main)`
- **차트 시리즈 서브 (기본)**: `var(--mg-color-secondary-main)`
- **성장 배지 (상승)**: `var(--mg-badge-growth-increase-bg)`, `var(--mg-badge-growth-increase-text)`
- **성장 배지 (하락)**: `var(--mg-badge-growth-decrease-bg)`, `var(--mg-badge-growth-decrease-text)`
