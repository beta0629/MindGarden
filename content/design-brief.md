- 유지할 브랜드: 크림 표면(`#F5F0E6` / `#F7F3EC`), 나비 로고, Pretendard 본문 + 한글 명조 디스플레이. 본문 잉크는 크림 대비 4.5:1 이상(가이드 `#1C2430` 또는 `#2E1F1A` 계열). `#9B6546`은 본문색으로 쓰지 않음.
- 한글: `word-break: keep-all`. 390에서 「시간」이 「시 간」으로 갈라지면 실패.
- 건너뛰기 링크. 페이지당 `h1` 1개. 카드 플립/호버에 본문을 숨기지 않음.
- 의료광고: 「완치」「효과 보장」금지. 「치료」는 놀이·미술 등 기법명 외 마케팅 강조에 쓰지 않음. 별점·효과·「생생한 후기」 모듈은 쓰지 않는다. 후기는 이용 경험(시설·응대·예약 편의) 익명 카드만, 관리자 승인 글만. 연동 영상·블로그 카드의 제목·설명, 배너 문구에도 같은 주의를 적용한다. 배너는 효과 보장·할인 과장·후기 인용을 금지하고, 가격 할인 표시는 사실만 쓴다.
- design-taste: 보라 그라데이션, 이모지 아이콘, 동일 3–4카드 남용, 무한 바운스·블링크 금지.

## 4. 3D·모션 (차분한 홈)

- 방향: Blender 3D 에셋과 모션 액션이 들어간, 과하지 않은 상담센터 홈.
- 3D 원본은 Blender로 제작한 glTF/GLB, 또는 사전 렌더 영상·이미지 시퀀스. 웹에서 실시간 렌더가 필요하면 React Three Fiber(R3F, three.js)를 우선 검토한다. 상담 홈의 기본안은 **사전 렌더(무음 짧은 영상 또는 스틸)** 를 히어로·공간 섹션에 쓰고, 실시간 GLB는 핵심 1개 섹션을 넘기지 않는다.
- 스크롤 연동 모션은 느리고 부드럽게(긴 이징, 작은 이동, 한 번만 재생). 섹션 진입은 페이드+짧은 상승(24px 이내, 400–600ms, ease-out, 1회).
- `prefers-reduced-motion: reduce`이면 모든 애니메이션·자동 슬라이드·3D·영상을 정지하고 포스터/대체 이미지만 보여 준다.
- 저사양·모바일: WebGL을 켜지 않거나 첫 프레임 스틸만. 네트워크가 느리면 영상·GLB를 불러오지 않는다.
- Lighthouse 90+ 전략: LCP 요소는 포스터/스틸(3D·영상은 LCP가 되지 않게). 히어로 영상 약 1.5MB 이하(가능하면 1MB), GLB는 압축(Draco 등) 후 지연 로딩, `preload="metadata"`. 무한 루프 장식 모션은 쓰지 않는다.
- Blender 에셋 제작 담당은 앱웹 디자인으로 확정(2026-11-11).

주소: 인천 연수구 해돋이로120번길 23 아크리아2 2층 204호. 위치 안내로 「해양경찰청 인근」을 쓴다(상담사 경력으로 쓰지 않음). 확인된 거리: 버스 330번 해양경찰청 하차 후 도보 약 176m(약 2분). 현 사이트의 지하철·버스·주차 안내. 지도. 예약 CTA.

**체크리스트** `/screening`  
주제별 간이 점검. 의료 평가 대체 아님 고지, 결과 후 예약 경로.

**법적** `/privacy`, `/terms` (신규)  
푸터 링크. 원고는 세무·법률 봇이 작성·검토하고, 재학이 확인한다.

**후기** `/reviews`  
기본 시안에서 제외하거나 플레이스 후기 안내만. 자체 작성 폼·별점·효과 항목은 넣지 않음.

**이벤트·광고 배너** (모듈, 별도 경로 아님)  
관리자 배너 관리 화면에서 등록·수정·삭제(삭제 전 확인 창), 노출기간·순서·on/off를 한다. 위치: 홈 메인 하단 띠배너, 홈 중간 슬롯, 상단 공지 띠(닫기 가능), 서브페이지 사이드 또는 하단 슬롯. 이미지와 대체텍스트는 필수. 자동 슬라이드에는 정지 버튼을 두고(WCAG), `prefers-reduced-motion`이면 자동 슬라이드를 끈다. 슬롯은 고정 비율로 레이아웃이 흔들리지 않게 한다. 문구 검수: 효과 보장·할인 과장·후기 인용 금지, 가격 할인 표시는 사실만. 시안에 각 슬롯(390+1440)과 관리자 배너 관리 화면을 요청한다.

**이벤트·프로모션 가격** (관리자 모듈)  
관리자에서 항목명, 금액, 시작일시와 종료일시(KST), on/off를 등록·수정·삭제(삭제 전 확인 창)한다. 기간이 되면 서버 시각 기준으로 자동 노출·종료된다. 이벤트 배너와 연결할 수 있다. 표시는 사실만(기간·조건 명시, 과장 금지). 「첫 마음산책 60,000원」은 이 모듈로 기간 한정 노출하며, 기간 밖·off이면 「첫 상담은 1시간입니다」만 안내한다(금액 추정 금지). 시안에 관리자 「이벤트·프로모션 가격」화면을 요청한다.

**관리자** `/admin` (공개 시안 범위 밖, 별도 관리자 시안)  
데스크톱 우선이되 태블릿·모바일에서도 문의 목록을 볼 수 있게. 마케팅 사이트 헤더·하단 문의 시트를 관리자에 쓰지 않음. Clinic-OS와 다른 로그인. 배너 관리 화면: 등록·수정·삭제(삭제 전 확인 창), 노출기간·순서·on/off. 이벤트·프로모션 가격 관리 화면: 항목명·금액·시작·종료 일시(KST)·on/off, 등록·수정·삭제(삭제 전 확인 창).
