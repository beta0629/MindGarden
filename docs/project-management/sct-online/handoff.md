# 코어 핸드오프 · 마인드가든 문장완성 질문지(온라인)

리더 라우팅 전용. 레이아웃은 코어에 직접 넘기지 않음. 시안 = `/workspace/client-web-app-content-map/sct-online/`.

## 범위
1. 내담자 공개 링크(로그인 없음) 응답 흐름 — **모바일 375·414 최우선**.
2. 관리자: 내담자 상세 「질문지」 탭 + 보내기 시트 + 발송 상태 목록. 메뉴 추가 없음.
3. 상담사: 상담일지 작성 화면 옆 질문지 패널(영역별·번호순·빈 응답만·영역 메모).
- 테넌트: **마인드가든만**(기능 플래그). 다른 테넌트에는 탭·패널 모두 숨김.

## 데이터(제안 · 코어가 확정)
- `questionnaire_template`(마인드가든 · adult/teen/child · v3 · 문항 50 · 영역 매핑 · 고지 문구 버전) — 문구는 v3.md 그대로 시드.
- `questionnaire_send`(내담자, 종류, 채널·대상 해시, 토큰, 보낸 사람, 보낸 시각, 기한, 상태, requires_guardian)
- `questionnaire_answer`(send, 번호, 텍스트, not_applicable, 저장 시각) — 문항 단위 upsert.
- `questionnaire_consent`(send, 종류: 민감정보/보호자, 문구 버전, 시각, 보호자 이름·관계·인증)
- `questionnaire_memo`(send, 영역, 상담사, 본문) — 상담사만.

## 확인 방법(증상 기준)
- 375·414 실기기(iPhone Safari, Galaxy Chrome)에서 키보드를 열어도 입력 중인 칸과 「다음」이 보인다(spec 3.2).
- 저장 표시가 저장됨/저장 중/연결 끊김으로 바뀌고, 링크를 다시 열면 「이어서 작성」이 나오며 다음 묶음으로 연다.
- 문항 문구가 v3.md와 한 글자도 다르지 않다(파서 검증 기준 spec 0).
- 관리자 목록 상태가 상태 정의표(spec 4)대로 바뀐다. 같은 종류를 다시 보내면 이전 건은 만료, 답은 보관.
- 상담사 패널은 제출 전 내용 비공개.

## 미결 사항 (재학·센터 규정·법률 확인)
1. **링크 기본 기한**: 시안 7일(3·7·14 선택). 기한 지나면 쓰던 답은 보관만? 새 링크에서 이어 쓰기 허용?
2. **본인 확인 방식**: 시안은 보낸 번호/이메일 직접 입력 일치. 대안 = 문자 인증번호(OTP). 실패 허용 횟수(시안 5회) 후 잠금 시간?
3. **보호자 동의 수단**: 시안은 보호자 휴대폰 인증 + 체크. 법정대리인 확인 수준(PASS 본인인증 필요 여부), 서면 동의서 병행 여부. 만 14세 이상 청소년의 보호자 동의·열람 범위(별지 「센터 규정·법률 검토 확인 필요」).
4. **보관 기간·파기**: 응답·동의 기록 보유 기간(별지 「센터 규정 확인 필요: 보유 기간」), 상담 종결 후 처리.
5. **완료 화면 문구**: v3 끝 문장 「작성한 질문지는 상담 선생님께 전해 주세요」는 종이용. 온라인은 「제출했습니다 · 담당 상담사가 다음 상담에서 함께 살펴봅니다」로 시안 — 상담·지원 봇/재학 확인.
6. **동의 문구 원문**: 민감정보 동의(항목·목적·보관·거부권) 문구는 시안 자리값. 상담 동의서 원문·법률 검토본으로 교체.
7. **제출 전 열람**: 상담사가 진행 중 답을 볼 수 있는가(시안: 불가).
8. **위기 신호**: 별지 6항. 자동 감지·알림은 만들지 않음(점수화 금지 원칙). 제출 시 담당 상담사 알림만 둘지.
9. **아동 구술 입력**: 저학년은 상담사가 받아 적기 — 상담사 화면에서 대신 입력 + 「구술」 표시가 필요한가.
10. **센터 전체 발송 목록**: 시안은 내담자 상세 안에만. 센터 전체 목록이 필요하면 메뉴 위치 결정(메뉴 추가는 재학 승인 사항).
11. 이메일 발송 채널 사용 여부(시안은 문자 기본, 이메일 선택 가능).
