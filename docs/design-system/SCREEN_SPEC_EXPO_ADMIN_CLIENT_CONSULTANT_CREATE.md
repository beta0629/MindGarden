# 화면설계서: Expo 어드민 내담자/상담사 추가 (고도화)

## 1. 화면 개요
- **화면명**: 내담자 추가 (`create-client.tsx`), 상담사 추가 (`create-consultant.tsx`)
- **목적**: 기존 최소 필드만 제공되던 모바일 등록 폼을 웹 어드민 수준의 풀 폼(Full Form)으로 확장하되, 모바일 사용성에 맞게 레이아웃을 최적화함.
- **경로**: 어드민 > 사용자 관리 > FAB(+) > 내담자/상담사 추가

## 2. 레이아웃 및 사용성 (UX) 원칙
- **반응형/모바일 카드형 우선**: 입력 필드가 많으므로 '필수 정보'와 '선택(부가) 정보'를 시각적 카드(Card) 단위로 분리.
- **정보 노출 범위**: 
  - 내담자: 이름, 연락처(이메일/휴대폰) 필수 노출. 주소, 주민번호 등은 '추가 정보' 카드로 묶어 하단 배치.
  - 상담사: 이메일(필수), 전문분야, 자격/경력 등을 카드 단위로 분리.
- **공통 패턴**:
  - 상단: `AppTopBar` (뒤로가기, 타이틀)
  - 본문: `ScrollView` 기반. 각 카드는 `theme.colors.surface` 배경과 `theme.shadows.sm` 적용.
  - 하단: 고정(Fixed) 영역에 '저장' 버튼(`theme.colors.primary`) 배치 (사용자가 스크롤을 내려도 항상 접근 가능하도록).
  - 에러/성공 알림: 기존 `UnifiedModal` 재사용.

## 3. 필드 목록 및 검증

### 3.1 내담자 추가 폼
**[카드 1: 기본 정보 (필수)]**
- **이름**: Text Input (필수)
- **연락처**: Email Input 또는 Phone Input 중 택 1 필수.
  - 이메일 입력 시 `onBlur` 시점에 중복 확인 API 호출 및 결과 인라인 텍스트 노출.
- **비밀번호**: Password Input (선택, 미입력 시 서버 자동 생성)

**[카드 2: 부가 정보 (선택)]**
- **주민등록번호**: Text Input (앞 6자리 + 뒤 1자리 형식 마스킹)
- **주소**: Text Input (우편번호 검색 연동은 추후 고려, 현재는 단순 텍스트)
- **상담 목적/이력**: Multiline Text Input (최대 3줄)

### 3.2 상담사 추가 폼
**[카드 1: 계정 정보 (필수)]**
- **이메일**: Email Input (필수). 입력 후 '중복 확인' 버튼 또는 `onBlur` 검증 필수.
- **휴대폰**: Phone Input (선택)

**[카드 2: 전문 정보 (선택)]**
- **전문 분야**: Tag Input 또는 다중 선택(Chip) UI
- **자격 및 경력**: Multiline Text Input
- **등급**: Select/Dropdown (기본값 설정)
