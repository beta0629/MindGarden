# 어드민 대시보드 - 신규 내담자 유입 및 요일별 통계 UI/UX 스펙

**작성**: core-designer  
**일자**: 2026-07-28  
**목적**: 기존 `VisualizationGroup` 내에 신규 내담자 월별 유입(A) 및 요일별 상담 건수(B) 카드를 하단 1개 행(Row)에 나란히 추가하여, 관리자가 클릭 없이 테넌트 전체의 유입 추이와 요일 피크를 즉시 스캔할 수 있도록 개선합니다. 또한 신규 내담자 유입 카드 내에 **「총 내담자 현황」 KPI**를 추가하여 현재 총 내담자 규모를 함께 파악할 수 있도록 합니다.  
**기준**: `PENCIL_DESIGN_GUIDE.md`, 어드민 샘플(B0KlA), `ADMIN_DASHBOARD_PERIOD_STATS_VIZ_SPEC.md`, `ADMIN_DASHBOARD_BADGE_COLOR_SPEC.md`

## 2. 세부 UI/UX 스펙

모든 카드는 기존 섹션 블록 스타일(흰색/연회색 배경, 16px radius, 회색 테두리)을 유지합니다.

### 2.1 [A 카드] 신규 내담자 유입 차트 및 총 내담자 현황 KPI
기존 VisualizationGroup organism 내 molecule/헤더 슬롯을 확장하여 신규 카드를 만들지 않고 기존 카드 헤더 영역을 활용합니다.

#### 2.1.1 헤더 레이아웃 와이어프레임 (Flex Container)
```text
[데스크톱/태블릿 - row 배치]
┌─────────────────────────────────────────────────────────────────────────────┐
│ [좌측 영역: flex-col, gap: 4px]            [우측 영역: flex-col, gap: 4px, align: end] │
│ ┌──────────────────────────────────┐       ┌──────────────────────────────┐ │
│ │ 신규 내담자 유입 [▲ 12%]         │       │ 총 내담자 현황               │ │
│ │ 최근 6개월 신규 등록             │       │ 1,204 명                     │ │
│ └──────────────────────────────────┘       └──────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────────────┘

[모바일 - column 스택 배치]
┌───────────────────────────────────┐
│ [좌측 영역]                       │
│ 신규 내담자 유입 [▲ 12%]          │
│ 최근 6개월 신규 등록              │
│ --------------------------------- │
│ [우측 영역 (좌측 정렬로 변경)]    │
│ 총 내담자 현황                    │
│ 1,204 명                          │
└───────────────────────────────────┘
```

#### 2.1.2 헤더 좌측 (Left: 기존 유지 + 배지)
- **타이틀 행**: 
  - 텍스트: "신규 내담자 유입" (`var(--mg-v2-color-text-primary)`, 16px, fontWeight: 600)
  - 증감 배지: 타이틀 우측에 주식형 배지 표시 (상승: `var(--mg-badge-growth-increase-bg)`/`text`, 하락: `var(--mg-badge-growth-decrease-bg)`/`text`). KPI 숫자보다 시각적 위계를 낮춰 보조 지표로 기능하도록 함.
- **서브타이틀**: "최근 6개월 신규 등록" (`var(--mg-v2-color-text-secondary)`, 12px)

#### 2.1.3 헤더 우측 (Right: 신규 KPI)
- **데이터 정의**: 활성·목록노출 수 (대시보드 `stats.totalClients`와 동일. 신규 API 불필요, FE prop 재사용)
- **KPI 라벨**: "총 내담자 현황" (`var(--mg-v2-color-text-secondary)`, 12px)
- **KPI 수치 (큰 폰트)**: 
  - 숫자: `1,204` (`var(--mg-v2-color-text-primary)`, **24px**, fontWeight: 700)
  - 단위: "명" (`var(--mg-v2-color-text-secondary)`, 14px, 숫자와 baseline 정렬, gap: 4px)
- **계층 정리**: 우측의 큰 숫자(24px, Bold)가 가장 두드러지게 하여, 관리자가 클릭 없이 테넌트 전체 인원을 즉시 스캔할 수 있도록 강조.

#### 2.1.4 반응형 및 상태 (Responsive & States)
- **데스크톱/태블릿**: 헤더 컨테이너 `display: flex; justify-content: space-between; align-items: flex-start;`. 우측 영역은 텍스트 우측 정렬(`align-items: flex-end; text-align: right;`).
- **모바일 (좁은 폭)**: 좌/우 영역이 겹치지 않도록 `flex-direction: column; gap: 16px;` 로 줄바꿈(Stack) 처리. 모바일에서는 우측 영역도 좌측 정렬(`align-items: flex-start; text-align: left;`)로 변경하여 가독성 확보.
- **로딩 상태**: 큰 숫자 영역에 스켈레톤 UI (`width: 80px; height: 28px; border-radius: 4px; background: var(--mg-color-surface-main);` + pulse 애니메이션) 적용.
- **빈값(0) 상태**: 데이터가 0일 경우 "0 명"으로 정상 렌더링 (빈 상태 메시지로 대체하지 않음).

#### 2.1.5 차트 영역 (기존 유지)
- **차트 타입**: 세로 막대 차트 (Bar Chart)
- **시리즈 색상**: `var(--mg-color-primary-main)` (진한 올리브 그린)
- **수치 라벨 규칙**: 
  - 각 막대 상단 중앙(Top Outside)에 수치 표시
  - 폰트 토큰: `var(--mg-v2-color-text-secondary)`, 크기 12px
  - 수치가 `0`일 경우 라벨 미노출 처리하여 차트의 복잡도를 낮춤
- **i18n 키 제안 (`admin.json`)**:
  - `admin.dashboard.newClientInflow.title`: "신규 내담자 유입"
  - `admin.dashboard.newClientInflow.subtitle`: "최근 6개월 신규 등록"
  - `admin.dashboard.newClientInflow.totalClientsLabel`: "총 내담자 현황"
  - `admin.dashboard.newClientInflow.unit`: "명"

### 2.2 [B 카드] 요일별 상담 건수 차트
- **제목**: "요일별 상담 건수"
- **최다 요일 하이라이트 배지**: 제목 옆에 가장 높은 수치를 기록한 요일을 텍스트와 함께 표시
  - 예: `수요일` 텍스트 우측에 `[최다 · 32건]` 배지 표시
  - 배지 토큰: `var(--mg-color-surface-main)` 배경 + `var(--mg-color-text-primary)` 텍스트 (또는 기존 포인트 배지 토큰)
- **차트 타입**: 세로 막대 차트 (Bar Chart), X축은 월~일 고정
- **시리즈 색상**:
  - 기본 요일 막대: `var(--mg-color-secondary-main)` (차분한 그린/그레이 톤)
  - **최다 수치 요일 막대 (강조)**: `var(--mg-color-primary-main)` (진한 올리브 그린)
- **수치 라벨 규칙**: 
  - 막대 상단 중앙 위치, `var(--mg-v2-color-text-secondary)` 12px
  - 값이 0일 경우 미노출
  - **최다 요일의 라벨**: `var(--mg-v2-color-text-primary)` 폰트에 `fontWeight: 600`을 적용하여 굵게 강조

## 4. 코더 핸드오프 (구현 체크리스트 & 토큰)

본 스펙은 디자이너 시안 스펙이며, 실제 코드는 **core-coder**가 작성합니다. 아래 체크리스트를 확인하세요.

### 4.1 코더 체크리스트
- [ ] 하드코딩된 Hex 값(예: `#3D5246`)이 없는가? 오직 `var(--mg-*)` 계열 변수만 사용되었는가?
- [ ] `VisualizationGroup` 컴포넌트 내부 하단에 A, B 카드가 2열(데스크톱) / 1열(모바일)로 반응형 배치되었는가?
- [ ] A카드 헤더가 좌측(타이틀+배지+서브타이틀)과 우측(KPI 라벨+큰 숫자)으로 분리되어 렌더링되는가?
- [ ] 모바일 뷰에서 A카드 헤더가 차트와 겹치지 않고 세로로 스택(줄바꿈) 처리되는가?
- [ ] 총 내담자 현황 숫자는 FE의 기존 `stats.totalClients` 값을 재사용하여 표시하는가? (PII 비노출)
- [ ] BEM 클래스명 규칙 또는 `mg-v2-ad-b0kla__*` 접두사를 준수했는가? (예: `mg-v2-ad-b0kla__kpi-container`, `mg-v2-ad-b0kla__kpi-value`)
- [ ] 증감률 배지 컴포넌트(`StatusBadge` 계열)에 올바른 상승/하락 파스텔톤 클래스가 매핑되었는가?
- [ ] i18n 다국어 키(`admin.json`)가 올바르게 적용되었는가?
- [ ] E2E 및 단위 테스트를 위한 `data-testid` 속성이 주요 요소에 추가되었는가? (예: `data-testid="new-client-kpi-total"`, `data-testid="new-client-kpi-label"`)

### 4.2 필수 사용 CSS 변수 정리
- **배경 및 레이아웃**: `var(--mg-color-background-main)`, `var(--mg-color-surface-main)`
- **테두리 및 그리드**: `var(--mg-v2-color-border-default)`
- **텍스트**: `var(--mg-v2-color-text-primary)`, `var(--mg-v2-color-text-secondary)`
- **차트 시리즈 메인 (강조)**: `var(--mg-color-primary-main)`
- **차트 시리즈 서브 (기본)**: `var(--mg-color-secondary-main)`
- **성장 배지 (상승)**: `var(--mg-badge-growth-increase-bg)`, `var(--mg-badge-growth-increase-text)`
- **성장 배지 (하락)**: `var(--mg-badge-growth-decrease-bg)`, `var(--mg-badge-growth-decrease-text)`
