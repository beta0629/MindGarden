## 핵심 결정
1. **히어로**: 3D 나비는 그대로 두었다.
   - 데스크톱은 glb + tilt(최대 7°) + 30초 orbit이다. 시안에는 orbit 정지 프레임을 넣었다.
   - 모바일은 orbit 영상(가로 크롭 390×260)과 44px 일시정지 버튼이다. reduced-motion이면 포스터에서 멈춘다.
   - 모바일 히어로 텍스트는 원고대로다. 히어로에 운영 시간은 없다.
2. **상담 분야**: VectorCraft 일러스트 카드 2+2를 7/5·5/7로 엇갈렸다.
   - 넓은 카드는 일러스트를 오른쪽에 크게 두고, 좁은 카드는 오른쪽 위에 작게 둔다.
   - 모바일은 64px 일러스트가 달린 행 목록이다.
3. **상담 절차**: 데스크톱은 샌드 띠 위 가로 4단 스테퍼(88px 일러스트 + 연결선)다. 모바일은 2×2 타일이다.
   - 일러스트 8종은 64 그리드, 잉크 2pt 라운드 선, garden 포인트 선, 샌드 블롭 하나로 맞췄다.
4. **상담사 소개**: 사진을 글보다 크게 두었다(3:4).
   - 원본 사진이 없어 라벨 붙은 사진 자리로 두었다.
5. **이벤트 배너 B**: 데스크톱 6:1, 모바일 3:1(750×250 기준).
   - 꽃 실사 + 제목·기간 + 네이버 플레이스 링크다.
   - 기간이 지나면 숨긴다(관리자 주석).
   - 하단 배너 C는 원고 지시대로 뺐다. 공지 띠 A는 남겼다.
6. **센터 공간**: 큰 16:9 모래놀이실 + 4:3 2×2(미술·놀이·언어·가족)이고, 캡션은 크림 칩이다.
   - 「공간 더 보기」 링크는 원고에 있는 것을 따랐다.
7. **소식·콘텐츠**: 영상은 16:9 썸네일 3개(재생 배지)다. 모바일은 264px 카드 가로 스크롤(다음 카드 살짝 보임)이다.
   - 블로그는 썸네일 가로형 카드 3개다.
   - 제목·날짜는 RSS 실데이터다.
8. **예약·문의**
   - 예약 경로는 네이버 플레이스 링크 하나다(외부 링크 아이콘).
   - 문의 폼의 동의 체크는 기본 해제다. 건강 정보 기재 금지 문구를 넣었다.

   - 미니 오시는 길(주소·지도 보기·전화)을 넣었다.
   - 모바일은 문의 폼을 「문의 폼 열기」로 접었다(디자인 제안, 열린 질문 5).
