## 1. 개요 및 배경

### 1.1 배경
Phase 1에서 `/erp/dashboard`를 운영자 전용 **머니 콕핏(Money Cockpit)**으로 재구축한 데 이어, Phase 2에서는 운영자가 가장 자주 사용하는 **단일 장부(ONE Operator Ledger)** 화면을 `/erp/financial`에 구축한다.

기존의 `FinancialManagement`와 `IntegratedFinanceDashboard`는 10개에 달하는 탭(대시보드, 거래 내역, 분개장, 원장, 재무제표, 손익계산서, 현금흐름표, 일/월/연 리포트, 정산 등)과 차변/대변, 계정과목 등 복잡한 회계 전문 용어로 운영자의 접근성을 차단하고 있었다.

### 1.2 목표
1. **운영자 중심 단일 장부**: 10개 탭을 나열하지 않고, 직관적인 **들어온 돈 · 나간 돈** 단일 뷰로 전환한다.
2. **단순한 탐색 및 기록 흐름**: [기간 선택] → [합계 확인] → [목록 필터/스캔] → [`돈 기록` 원클릭 CTA].
3. **회계 복잡도 격리**: 차변/대변/분개/재무제표 등 세무·회계용 도구는 기본 뷰에서 완전히 제거하고 하단 `세무사용 자료` Disclosure(접이식 영역) 뒤로 숨긴다.
4. **moneyCockpit 독립성 유지**: `frontend/src/components/erp/organisms/moneyCockpit/**` 및 `operatorFinanceDashboardStrings.js`는 일체 수정하지 않는다.

## 2. 사용성 · 정보 노출 · 레이아웃 계약 (§0.4)

### 2.1 사용성 원칙
- **사용자 관점**: 센터장/원장은 회계사가 아니다. "차변에 현금, 대변에 매출"을 입력하게 만들면 안 되며, "상담료 100,000원이 들어왔다" 또는 "임대료 1,500,000원이 나갔다"를 기록하고 확인하는 것이 목적이다.
- **방해 없는 빠른 흐름**: 탭 전환 없이 한 화면에서 상단 요약(들어온 합, 나간 합, 남은 돈)을 보고 바로 아래 목록을 확인하며, 우측 상단 `돈 기록` 버튼으로 즉시 기록한다.

### 2.2 정보 노출 규칙
| 구분 | 기본 노출 (Primary View) | 숨김 / Disclosure 뒤로 격리 (Secondary) |
|------|-------------------------|---------------------------------------|
| **표시 항목** | • 일자 (Date)<br>• 내용 (Description)<br>• 들어온 금액 (Income)<br>• 나간 금액 (Expense)<br>• 카테고리는 내용 하단 secondary text | • 차변 (Debit) / 대변 (Credit)<br>• 분개 (Journal Entries) / 원장 (Ledgers)<br>• 대차대조표 (자산·부채 현황)<br>• 손익계산서 (손익 현황)<br>• 현금흐름표<br>• 정산 규칙<br>• 일간 / 월간 / 연간 리포트 |
| **금액 표기** | • `formatKrw` 필수 (`1,234,000원` 형태, ko-KR + 원)<br>• **「순이익」 라벨 금지** → 「남은 돈」<br>• **「건」 라벨 금지** (금액에 집중) | — |
| **탭 구조** | • 상단 대시보드 탭 완전 제거<br>• 뷰 모드 토글: `테이블`(기본) \| `달력` (데이터를 보는 방식의 전환) | • `세무사용 자료` disclosure 클릭 시 확장되어 기존 재무제표 뷰 및 리포트 접근 제공 |

## 3. 섹션별 상세 스펙

### 3.1 Quiet Page Header
페이지 최상단에 위치하며, 여백을 낭비하지 않는 단일 라인 형태(Compact Dense)를 지향한다.

```
[Desktop Layout]
┌────────────────────────────────────────────────────────────────────────────────┐
│ 들어온 돈 · 나간 돈    [ 이번 달 | 지난달 | 올해 | 직접 ]            [+ 돈 기록] │
└────────────────────────────────────────────────────────────────────────────────┘
```

- **제목**: `들어온 돈 · 나간 돈`
  - 토큰: `var(--mg-v2-font-size-h1)` (1.75rem / 28px), `font-weight: 700`
  - 색상: `var(--mg-v2-color-text-primary)` (`#0F172A`)
  - 테넌트 서브타이틀, `(테넌트: ...)` 표시 금지
- **기간 세그먼트 (Period Segment)**:
  - 위치: 제목 우측 인라인 배치 (Desktop)
  - 옵션: `이번 달` | `지난달` | `올해` | `직접` (단일 선택)
  - 컴포넌트: `BadgeSelect` 또는 `SegmentedTabs` 형태의 Quiet Segment
  - 활성 스타일: 배경 `var(--mg-v2-color-primary-main)` (`#0E5F5A`), 텍스트 `#FAF9F7`
  - 비활성 스타일: 배경 투명, 텍스트 `var(--mg-v2-color-text-secondary)` (`#475569`)
  - '직접' 선택 시: 인라인 날짜 범위 팝오버/인풋 확장
- **Primary Action (`돈 기록` CTA)**:
  - 위치: 헤더 우측 끝
  - 컴포넌트: `MGButton` (variant: solid primary)
  - 스타일: 배경 `var(--mg-v2-color-primary-solid)` (`#0E5F5A`), 높이 40px, 패딩 10–20px, radius 10px
  - 텍스트: `+ 돈 기록` (또는 `돈 기록`)
  - 클릭 동작: [들어온 돈 / 나간 돈] 통합 등록 모달(`MoneyRecordModal`) 오픈

### 3.2 Compact Summary Strip (요약 스트립)
헤더 바로 아래 위치하여 선택된 기간의 핵심 현금 흐름 총액을 즉시 파악하도록 한다.

```
┌────────────────────────┬────────────────────────┬────────────────────────┐
│ 들어온 합              │ 나간 합                │ 남은 돈                │
│ 14,250,000원           │ 8,400,000원            │ 5,850,000원            │
└────────────────────────┴────────────────────────┴────────────────────────┘
```

- **구성**: 가로 3분할 그리드 (`grid-template-columns: repeat(3, 1fr)`)
- **컨테이너 스타일**:
  - 배경: `var(--mg-v2-color-neutral-100)` (`#F5F3EF`) 또는 연한 서페이스
  - 테두리: 1px solid `var(--mg-v2-color-neutral-300)` (`#D4CFC8`)
  - Border Radius: `var(--mg-v2-radius-lg)` (12–16px)
  - 패딩: `var(--mg-v2-space-4)` ~ `var(--mg-v2-space-5)` (16–20px)
  - 좌측 컬러 악센트 바, 아이콘, 스프라이트 일체 금지
- **슬롯별 데이터 스펙**:
  1. **슬롯 1 (들어온 합)**:
     - 라벨: `들어온 합` (`var(--mg-v2-font-size-caption)` 0.75rem / 12px, `var(--mg-v2-color-text-secondary)`)
     - 금액: `formatKrw(totalIncome)` → 예: `14,250,000원`
     - 타이포: `var(--mg-v2-font-size-h2)` (1.375rem / 22px) ~ `h1`, `font-weight: 700`, `tabular-nums`
     - 색상: `var(--mg-v2-color-text-primary)` (`#0F172A`)
  2. **슬롯 2 (나간 합)**:
     - 라벨: `나간 합` (`var(--mg-v2-font-size-caption)`, `var(--mg-v2-color-text-secondary)`)
     - 금액: `formatKrw(totalExpense)` → 예: `8,400,000원`
     - 타이포: `var(--mg-v2-font-size-h2)`, `font-weight: 700`, `tabular-nums`
     - 색상: `var(--mg-v2-color-text-primary)` (`#0F172A`)
  3. **슬롯 3 (남은 돈)**:
     - 라벨: `남은 돈` (**「순이익」 표기 절대 금지**)
     - 금액: `formatKrw(netRemaining)` → 예: `5,850,000원` (음수일 경우 `-1,200,000원`)
     - 타이포: `var(--mg-v2-font-size-h2)`, `font-weight: 700`, `tabular-nums`
     - 색상: 양수 시 `var(--mg-v2-color-primary-main)` (`#0E5F5A`), 음수 시 muted brick (`#A84848`) 또는 primary slate
- **금지 사항**:
  - `(건수: 42건)` 또는 `42건` 등 건수 라벨 노출 금지
  - 「순이익」, 「영업이익」 등 전문 회계 용어 라벨 금지

### 3.3 Main Stage: 필터 바 & 기본 테이블 & 뷰 토글

#### 3.3.1 필터 툴바 & 뷰 토글 (Inline Controls)
테이블 상단에 위치하는 경량 인라인 컨트롤 영역이다.

```
┌────────────────────────────────────────────────────────────────────────────────┐
│ [🔍 내용 검색...       ]  [유형: 전체 ▾]  [카테고리: 전체 ▾]       [ ▤ 테이블 | 📅 달력 ] │
└────────────────────────────────────────────────────────────────────────────────┘
```
- **좌측 필터 그룹**:
  - 검색 인풋: 내용(거래처, 적요) 검색
  - 유형 필터: `전체` | `들어온 돈` | `나간 돈`
  - 카테고리 필터: `전체` | `상담료` | `급여` | `임대료` | `관리비` | `기타` 등
- **우측 뷰 토글 (View Mode Toggle)**:
  - 옵션: `테이블` (기본값) \| `달력`
  - 컴포넌트: `ViewModeToggle` 또는 `SegmentedTabs`
  - 설명: 대시보드와 동등한 레벨의 탭이 아니며, 장부 목록을 표로 볼 것인지 달력으로 볼 것인지의 **시각화 모드 전환**이다.
  - 대시보드(Overview) 탭은 여기서 완전히 제거된다.

#### 3.3.2 기본 뷰: 거래 테이블 (Ledger Table)
장부의 핵심 정보 4가지를 명확하게 표시한다.

| 컬럼명 | 표시 내용 및 스타일 | 정렬 | 비고 |
|--------|-------------------|------|------|
| **일자** | `YYYY-MM-DD` (예: `2026-08-27`)<br>토큰: `body-md`, `font-variant-numeric: tabular-nums` | Left | 기준일 |
| **내용** | **주 텍스트**: 거래 내용 / 적요 (`body-md`, weight 600)<br>**보조 텍스트 (Secondary)**: 카테고리명 (`caption` 0.75rem, `var(--mg-v2-color-text-secondary)`) | Left | 카테고리는 내용 하단 보조 텍스트로 결합하여 가로 공간 절약 |
| **들어온 금액** | 수입 거래: `formatKrw(amount)` (예: `150,000원`)<br>지출 거래: `—`<br>색상: `var(--mg-v2-color-primary-main)` (`#0E5F5A`) 또는 text-primary | Right | `tabular-nums`, weight 600 |
| **나간 금액** | 지출 거래: `formatKrw(amount)` (예: `50,000원`)<br>수입 거래: `—`<br>색상: `var(--mg-v2-color-text-primary)` (`#0F172A`) | Right | `tabular-nums`, weight 600 |
| **관리 (선택/호버)** | `수정` / `삭제` 아이콘 버튼 (`MGButton` ghost) | Right | 행 호버 또는 우측 최소 너비 배치 |

- **테이블 디자인 토큰**:
  - 행 높이: 48px ~ 52px (터치 및 밀도 최적화)
  - 헤더 스타일: 배경 `var(--mg-v2-color-neutral-100)`, 폰트 `caption`, weight 600, 텍스트 `var(--mg-v2-color-text-secondary)`
  - 구분선: 1px solid `var(--mg-v2-color-neutral-300)`
  - Empty State: `해당 기간에 등록된 내역이 없습니다.` (`EmptyState` 컴포넌트, 이모지 없음)

#### 3.3.3 달력 뷰 토글 시 (`LedgerCalendar`)
- 테이블·달력은 동일 `.operator-ledger-stage` 카드 지오메트리(테두리·radius·배경·`min-height: 36rem`)를 공유한다. 이중 크롬·독립 KPI·**독립 calendar month state** 금지.
- `monthYm`은 페이지 기간 필터가 SSOT. 달력은 quiet month caption + prev/next로 **페이지 `filters.monthYm`(및 해당 월 date bounds)만 mutate**할 수 있다. 컴포넌트 내부 월 state는 두지 않는다. Next는 현재 월 초과 금지, Prev는 `2020-01` 미만 이동 차단.
- 달력은 해당 월만 `size: 1000`으로 별도 fetch(테이블 페이지네이션과 분리).
- 셀: 좌상단 일자 번호 + 최대 2줄 `formatKrw`(들어온 `+` primary / 나간 `−` text-primary). 모바일은 점(dot)만.
- 일자 클릭은 선택만(모달 비오픈). 같은 stage 안(하단 또는 wide desktop 우측)에 당일 목록. 빈 날: `이 날짜에 등록된 내역이 없습니다.` 선택일 패널에 quiet `이 날짜에 기록` → MoneyRecordModal을 해당 YMD + EXPENSE로 프리필.
- `올해` 기간이어도 히트맵이 아니라 `monthYm` 한 달 그리드.

### 3.4 Disclosure Only: `세무사용 자료` (Tax Statements & Reports)
운영자 기본 장부 화면 하단에 아코디언/디스클로저 형태로 배치하여, 평소에는 접혀 있다가 세무사 제출이나 회계 감사 시에만 펼쳐보도록 한다.

```
┌────────────────────────────────────────────────────────────────────────────────┐
│ ▶ [세무사용 자료]  세무사·회계사 제출용 법정 재무제표 및 상세 리포트를 확인합니다. │
└────────────────────────────────────────────────────────────────────────────────┘

[펼쳤을 때 (Expanded State)]
┌────────────────────────────────────────────────────────────────────────────────┐
│ ▼ [세무사용 자료]                                                               │
│ ────────────────────────────────────────────────────────────────────────────── │
│ [ 탭: 손익 현황 | 자산·부채(대차대조표) | 현금흐름 | 거래정리(분개) | 계정별(원장) | 리포트 ] │
│                                                                                │
│ [ 해당 재무제표 / 리포트 컴포넌트 임베드 뷰 ]                                      │
└────────────────────────────────────────────────────────────────────────────────┘
```

- **디스클로저 헤더**:
  - 텍스트: `세무사용 자료` (`var(--mg-v2-font-size-h2)` 1.375rem 또는 `body-md` weight 700)
  - 캡션: `세무사·회계사 제출용 법정 재무제표 및 상세 회계 리포트` (`caption`, `#64748B`)
  - 아이콘: ChevronDown / ChevronRight
  - 서페이스: `var(--mg-v2-color-neutral-100)`, radius 12px, border 1px solid `var(--mg-v2-color-neutral-300)`
- **내부 포함 컴포넌트 (Sub-tabs / Links)**:
  1. **손익 현황** (`income-statement` / 손익계산서)
  2. **자산·부채 현황** (`balance-sheet` / 대차대조표)
  3. **현금 흐름** (`cash-flow` / 현금흐름표)
  4. **거래 정리** (`journal-entries` / 분개장)
  5. **계정별 내역** (`ledgers` / 총계정원장)
  6. **기간별 리포트** (`daily` / `monthly` / `yearly` 리포트)
  7. **정산 관리** (`settlement`)
- **원칙**: 기본 뷰에서는 이 컴포넌트들이 로드되지 않거나 접힌 상태로 존재하며, 운영자 화면을 절대 방해하지 않는다.

### 3.5 `돈 기록` 통합 등록 모달 (`MoneyRecordModal`)

`+ 돈 기록` 버튼 클릭 시 노출되는 단일 통합 모달이다. `UnifiedModal` 공통 컴포넌트를 사용한다.

```
┌─────────────────────────────────────────────────────────┐
│ 돈 기록                                             [X] │
├─────────────────────────────────────────────────────────┤
│ 유형                                                    │
│ [  ● 들어온 돈 (+)   |   ○ 나간 돈 (-)  ]               │
│                                                         │
│ 일자                                                    │
│ [ 2026-08-27                                       📅 ] │
│                                                         │
│ 금액                                                    │
│ [ 150,000                                           원 ] │
│                                                         │
│ 내용 (적요)                                             │
│ [ 예: 8월 4회차 상담료 입금                           ] │
│                                                         │
│ 카테고리                                                │
│ [ 상담료 ▾                                            ] │
│                                                         │
│ (선택) 메모 / 거래처                                    │
│ [ 홍길동 내담자                                       ] │
├─────────────────────────────────────────────────────────┤
│ [ 취소 ]                                      [ 기록하기 ] │
└─────────────────────────────────────────────────────────┘
```

- **필드 구성**:
  1. **거래 유형 선택 (세그먼트 / 라디오)**:
     - `들어온 돈 (+)` (기본값) \| `나간 돈 (-)`
  2. **일자**: Date picker (기본 오늘)
  3. **금액**: 숫자 입력 시 실시간 `formatKrw` 콤마 서식 지원 (`원` 접미사)
  4. **내용**: 거래 설명 입력 (필수)
  5. **카테고리**: 드롭다운 선택
     - 들어온 돈: 상담료, 패키지 결제, 환불 회수, 기타 수입 등
     - 나간 돈: 급여/수당, 임대료, 관리비, 소모품비, 환불 지급, 세금, 기타 지출 등
  6. **메모 / 내담자(상담사) 연결 (선택)**: 단일 텍스트 또는 콤보박스
- **차변/대변 자동 처리**:
  - 사용자는 차변/대변을 직접 고르지 않는다.
  - 프론트/백엔드 비즈니스 로직에 의해 [유형 + 카테고리]에 따라 내부 표준 분개가 자동 생성된다.

`RESPONSIVE_LAYOUT_SPEC.md` 및 `PENCIL_DESIGN_GUIDE.md`를 준수한다.

- **Main Stage**: 필터 바 + 뷰 토글 1행, 테이블 풀 너비 4컬럼 (`일자`, `내용(카테고리)`, `들어온 금액`, `나간 금액`).

### 5.2 Tablet (768px ~ 1279px)
- **Header**: 
  - 1행: 제목 + `돈 기록` CTA
  - 2행: 기간 세그먼트

- **Main Stage**: 테이블 컬럼 유지, 패딩 축소 (16px).

### 5.3 Mobile (<768px)
- **Header**: 
  - 1행: 제목 `들어온 돈 · 나간 돈`
  - 2행: 기간 세그먼트 (가로 스크롤 또는 4등분 버튼 그리드)

  - 각 행: 좌측 라벨, 우측 거대 금액 정렬.
- **Main Stage (테이블 모바일 최적화)**:
  - 행당 2단 카드형 레이아웃 전환:
    - 1단: 일자 (좌) | 카테고리 뱃지 (우)

- **Disclosure**: 하단 탭 리스트 세로 스택.
